This update defines a **complete UI theme direction** based on the provided logo and branding, including:

- Visual identity alignment

**Blue Haven Hotel**

- Replace any previous or placeholder names
- Ensure consistency across:
  - Navbar

# 🎨 UI THEME DIRECTION

## Core Inspiration

Based on the logo:

- Tropical
- Coastal / Oceanic
- Relaxed but premium
- Clean and modern with a vacation feel

---

## Color Palette

### Primary Colors

- Deep Ocean Blue (Primary UI color)
- Aqua / Teal (Secondary accents)
- Sunset Gold (Highlight / CTA elements)

---

### Supporting Colors

- Soft Sand / Beige (Backgrounds)
- White (Clean surfaces)
- Light Sky Blue (Subtle UI accents)

---

## Usage Rules

- Blue = Structure (navbars, headers, key UI elements)
- Aqua = Interaction (hover states, highlights)
- Gold = Calls to action (buttons, important indicators)

---

# 🌊 VISUAL STYLE

## Design Language

- Smooth curves (inspired by waves)
- Soft edges (rounded components)
- Light gradients (ocean + sunset tones)

---

## UI Feel

- Calm and fluid
- Modern but inviting
- Not overly sharp or rigid

---

# 🧭 NAVIGATION STYLE

## Navbar

- Use:
  - Deep blue background
  - White or light text
- Add subtle:
  - Wave gradient accents
- Keep:
  - Clean spacing
  - Clear hierarchy

---

# 🧩 COMPONENT STYLING

## Cards / Panels

- Rounded corners
- Soft shadows
- Light background (white or sand tone)

---

## Buttons

### Primary Button

- Aqua / Blue gradient
- Smooth hover transitions

---

### Secondary Button

- Outline style
- Light hover glow

---

## Highlights

- Use gold accents sparingly for:
  - Important actions
  - Notifications
  - Status indicators

---

# 🖼️ ASSET USAGE (IMPORTANT)

## Instruction

- Utilize images from the **assets folder**

---

## Rule

- Asset names are **semantic**
- Use them **exactly as intended**

---

## Examples

- If asset name implies:
  - Beach → use for backgrounds or hero sections
  - Waves → use for dividers or UI accents
  - Palm → use for decorative elements

---

## Do NOT

- Randomly assign images
- Misuse assets outside their intended meaning

---

# 🌅 BACKGROUND DESIGN

## Options

- Light gradient (sky → ocean tones)
- Subtle beach or wave textures

---

## Rules

- Keep backgrounds:
  - Non-distracting
  - Light and breathable

---

# 🎮 THEME INTEGRATION WITH SYSTEM

## Arcade + Hotel Blend

- Maintain arcade features BUT:
  - Soften visuals to match hotel theme
  - Replace harsh neon with softer tropical tones

---

## Waiting Experience

- Should feel like:
  - Relaxing resort waiting area
  - Not intense or aggressive gameplay environment
